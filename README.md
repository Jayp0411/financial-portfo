# Financial Portfolio Management Dashboard

MERN portfolio management application with JWT authentication.

## Run
1. Start MongoDB.
2. Backend:
   `cd server`
   `npm install`
   Copy `.env.example` to `.env` and set `JWT_SECRET`.
   `npm run dev`
3. Frontend in a second terminal:
   `cd client`
   `npm install`
   `npm run dev`

Backend: http://localhost:5000
Frontend: http://localhost:5173
