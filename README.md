
# FinTrack - Full-Stack Financial Portfolio Dashboard

A full-stack financial portfolio management web application built using the MERN stack with JWT authentication.

## 🚀 Core Features
- **Secure Authentication:** Implementation of JSON Web Tokens (JWT) and bcrypt password hashing.
- **MVC Architecture:** Clean separation of concerns between backend controllers, routes, and database models.
- **Database Aggregation:** Leverages MongoDB's aggregation framework for efficient server-side balance calculations.
- **Dynamic Frontend:** Responsive UI built with React to handle asynchronous operations smoothly.

## 🛠️ Tech Stack
- **Frontend:** React.js, HTML5, CSS3, JavaScript (ES6+)
- **Backend:** Node.js, Express.js, RESTful APIs
- **Database:** MongoDB
- **Security:** JSON Web Tokens (JWT), bcrypt

## 📦 Installation & Setup
1. Clone the repository.
2. Navigate to the `/server` directory, run `npm install`, set up your `.env` file with `JWT_SECRET`, and start the backend using `npm run dev`.
3. Navigate to the `/client` directory, run `npm install`, and start the development server using `npm run dev`.
